---
title: "Control the browser"
description: "How to use Sofia to automate the built-in browser"
---

Computer-use in Sofia currently works through the built-in Sofia Browser. It does not yet mean full desktop control of Ubuntu, macOS, or Windows apps.

Sofia can open pages, click, fill forms, read page content, and take screenshots inside that browser. If you connect to a remote Sofia server, the browser runs on that remote worker.

Today, the supported path is the first-party `Sofia Browser` extension.

## Requirements

- Use the desktop app or a remote worker that exposes the Sofia Browser.
- Keep `Sofia Browser` enabled in `Settings > Library`.

Then go back to the session view and ask Sofia to open a website.
