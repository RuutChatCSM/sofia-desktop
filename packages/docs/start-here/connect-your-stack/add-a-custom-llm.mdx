<Note>
**Local provider setup.** A custom provider can stay entirely in your workspace. Sofia remains free, and you do not need to sign in to Sofia Cloud. For centrally managed team access, see [Adding a managed LLM provider](/cloud/share-with-your-team/managed-llm-provider).
</Note>

Because `Sofia` is built on `Sofia` primitives, we support everything that you could modify in `.sofia.json`, like adding a [model](https://github.com/RuutChatCSM/sofia/docs/models/). However, our recommendation is to add it to `/path-to-your-workspace/.config/engine/engine.json` instead of modifying `~/.config/engine/engine.json`.

Inside `/path-to-your-workspace/.config/engine/engine.json`:
```
{
  "provider": {
    "my-api": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "My model",
      "options": {
        "baseURL": "https://your API address/v1"
      },
      "models": {
        "model-name": {
          "name": "Model name"
        }
      }
    }
  }
}
```

### Functional example: Ollama (Qwen3 8B)

This setup a local [Ollama](https://docs.ollama.com/api/openai-compatibility) instance running `qwen3:8b`. 

```
{
  "provider": {
    "ollama": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Ollama",
      "options": {
        "baseURL": "http://localhost:11434/v1"
      },
      "models": {
        "qwen3:8b": {
          "name": "Qwen3 8B"
        }
      }
    }
  }
}
```

Pull the model first with `ollama pull qwen3:8b`, then make sure the Ollama server is reachable at `http://localhost:11434` with `ollama serve`

Open your desktop, change the provider name and voila! You have an fully local LLM running in your machine.

For teams, manage the provider in Sofia Cloud under [Models > Bring your Own Keys](/cloud/share-with-your-team/managed-llm-provider), then make it available from `Settings > Cloud Providers` in the desktop app.
