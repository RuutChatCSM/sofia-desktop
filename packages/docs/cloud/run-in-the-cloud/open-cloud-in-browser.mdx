Sofia Web is currently available for select customers. When your organization has it enabled, you can open a full Sofia instance in your browser. There is nothing to install and nothing to set up on your computer.

## Who can use it

Sofia Web is enabled per organization. If you do not see it in the sidebar, your organization does not have access yet — email [team@ruut.chat](mailto:team@ruut.chat) to request it.

Sofia Web is only available on hosted Sofia organizations. It is not available on self-hosted deployments.

## Open Sofia Web

1. Sign in to your organization dashboard.
2. Click `Sofia Web` in the sidebar.
3. Wait a few seconds while the workspace starts.
4. Open the new browser tab when it is ready.

  ![The Sofia Web page in the organization dashboard with the Open Sofia Web button](/images/cloud-sofia-web.png)
</Frame>

You are now looking at the full Sofia interface in your browser.

<Frame>
  ![Sofia Web open in a browser tab showing the full Sofia interface](/images/sofia-web-browser-tab.png)

## Sleep and persistence

The hosted instance sleeps when it is idle and wakes when you open it again. Files in the workspace persist across sleep, so you can close the tab and come back later without losing your work.

## Early-access limitation

During early access, the instance URL is itself the credential. Do not share it, paste it into public chats, or publish it anywhere public.

If you accidentally share the URL, ask an Sofia admin for help.
