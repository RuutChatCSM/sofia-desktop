Sofia Web gives your team a full Sofia workspace in the browser, hosted and managed for you — nothing to install. It is currently available for select customers; contact Sofia if your organization wants access.

## Deploy a hosted workspace

1. Open your org dashboard and go to `Shared Workspace`.
2. Click `Add workspace`.
3. Wait until the status becomes `Ready`.
4. Click `Connect`.

From the connection drawer you can choose `Open in web` to use Sofia Web directly in the browser, `Open in desktop`, or copy the `Connection URL` plus `Owner token` / `Client token`.

## Open it from the desktop app

The same hosted workspace also opens in the desktop app. From the connection
drawer, click `Connect` and copy the `Connection URL` plus `Owner token` /
`Client token`. In the desktop app, choose `Add workspace -> Connect custom
remote`, paste the connection URL and token, then click `Connect remote`.

## When to use Sofia Web

Use Sofia Web when your team needs a hosted Sofia runtime, a stable place for long-running tasks or messaging connectors, or one workspace that several people can open from the same org — especially for teammates who should not have to install anything.

## Notes

- Sofia Web is available for alpha customers. If you do not see it in your dashboard, email [team@ruut.chat](mailto:team@ruut.chat).
- A workspace must be `Ready` before it can be opened.
- Hosted workspace limits follow your Sofia plan.
- If you prefer to self-host a runtime instead, run `sofia-server` and connect the desktop app to that server URL.
